================================================================================
PIXELBUTTON CUSTOM COMPONENT
================================================================================
Component Type: Custom Canvas Widget
File: ui/pixel_button.py

Properties:
- Width: Configurable (default 160px, used: 200px sidebar, 220px footer)
- Height: Configurable (default 50px, used: 45px)
- Background Color: Configurable (surface0, green, red)
- Text Color: Configurable (text, red, base)
- Icon: Optional PhotoImage (18x18 pixels)
- Font: Courier, size 10, bold
- State: normal / disabled

Visual Features:
- Pixelated rounded corners using staircasing technique
- Pixel scale: 3 (for corner stepping)
- 3D shading with light/dark borders
- Hover effect with color lightening
- Press effect with color darkening and offset
- Disabled state with darkened color

Icon/Text Layout:
- Icon position: pixel_scale * 4 + 4 (left offset)
- Icon anchor: center
- Text position: icon_x + 16 (16px right of icon)
- Text anchor: w (left-aligned)
- Text vertical position: height // 2 + 2 (when pressed)

Color Calculations:
- Hover color: lighten(bg_color, 15)
- Shadow color: darken(bg_color, 20)
- Disabled color: darken(bg_color, 40)

Events:
- Mouse Enter: Show hover color
- Mouse Leave: Return to base color
- Mouse Press: Show shadow color with offset
- Mouse Release: Return to hover color and execute command
