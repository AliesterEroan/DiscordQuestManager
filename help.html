Discord Quest Manager - Help Guide

🎯 What is Discord Quest Manager?
Discord Quest Manager is a tool that helps you complete Discord quests by emulating game processes. It creates fake game executables that Discord can detect, allowing you to earn rewards without actually playing the games.

🚀 Getting Started

1. 📱 Launch the Application
Run DiscordQuestManager.exe to start the application.
2. ⏳ Wait for Database Loading
The app will load the games database from Discord's API. Wait until you see "● DATABASE READY" with the number of registered games.
3. 🔍 Search for Games
Use the search bar at the top to find the game you want to emulate. Type the game name and select it from the dropdown.
4. ➕ Add to Queue
Double-click on the searched game to add it to your quest queue. You can add multiple games to the queue.
5. 📁 Create Custom Folder (Optional)
Click the "+" button next to a queued game to create a custom folder on your desktop where the fake executable will be created.
6. ▶️ Start Quests
Click the "Start Quests" (Start Quests) button to begin the emulation process. Check the boxes next to games you want to run.

🖥️ Understanding the Interface

📋 Sidebar (Left Panel)
  • ⭐Favorites (Favorites): Quick access to your favorite games - add games you use frequently
  • 🕐Recent (Recent): Recently used games for quick access - shows last 10 games
  • 🧹Clean All Data (Clean All Data): Removes all dummy executables, favorites, and recent items
  • ⚙️Settings (Settings): Configure app preferences and themes
  • ❓Help (Help): Opens this help page
🎯 Main Content Area
  • 🔍Search Bar: Search and select games from the database
  • 📝Queue Display: Shows games currently queued for emulation with checkboxes
  • ➕+ Button: Creates a custom folder on desktop for the queued game's executable
  • 📍Location Icon: Opens the custom folder in file explorer (if folder was created)
  • ⏱️Timer: Shows remaining time for the current quest
  • 📊Progress Bar: Visual progress indicator
  • 📡Status: Shows current emulation status

⚙️ Settings Explained

🎨 General Tab (General)
  • 🌈Theme (Theme): Choose between different color themes (Mocha, Latte, Frappe, Macchiato, or Custom)
  • ⏰Quest Duration: Set how long each quest runs (default: 15 minutes)
  • 💾Remember Duration: Save your custom duration preference
  • 🔔Minimize to Tray: Minimize app to system tray instead of taskbar
  • 🧹Auto Clean on Exit: Automatically clean dummy files when closing the app
  • 🎮Multi-Quest Limit: Set maximum number of simultaneous quests (0 = unlimited)
  • 💬Discord Auto-Open: Offer to open Discord if not running
🐱 Dummy Window Tab (Dummy Window)
  • 🐱Cat Animation: Choose which cat animation to display in the dummy window (Cat-1 through Cat-6)
  • 🔊Alarm Sound: Enable/disable victory sound when quest completes
  • 🎵Alarm Type: Choose between default beep or custom sound
  • 📂Custom Sound Path: Select your own sound file for the alarm
  • 🔉Volume: Adjust the volume of the custom alarm sound (0-100%)
🖥️ System Tab (System)
  • 🔄Auto Check Updates: Automatically check for new versions on startup
  • 📁Default EXE Creation Path: Choose where fake executables are created
  • 💾Data Folder Location: Choose where settings and data are stored

🔧 How It Works

Quest Process Flow
  1. 📝 The app creates a fake executable file in the specified location
  2. 🐱 A dummy window opens displaying a cat animation
  3. 💬 Discord detects the "game" process running
  4. ⏱️ After the timer completes, the dummy window closes
  5. 🧹 The fake executable is cleaned up (if auto-clean is enabled)

🔧 Troubleshooting

📡 Database Won't Load

  • Check your internet connection
  • Try restarting the application
  • Check if Discord's servers are accessible

🐱 Dummy Window Won't Open

  • Check if your antivirus is blocking the app
  • Run the application as administrator
  • Check the debug.log file for errors

🔊 Custom Alarm Sound Not Playing

  • Ensure the sound file exists and is accessible
  • Check that the file format is supported (WAV, MP3, OGG, FLAC)
  • Verify the volume is not set to 0
  • Try using the test button in settings
